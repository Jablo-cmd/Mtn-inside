# MTN Inside — Connect. Belong. Thrive.

A mobile-friendly, static concept prototype for an employee community experience focused on connection, appreciation, shared interests, events, and wellbeing.

## Run locally
Open `index.html` in a modern browser. No build tools or dependencies are required.

## Current status
- Static front-end prototype only.
- Uses fictional demo names and sample content.
- Posts and reactions are local browser interactions only; there is no backend or persistent database.
- Employee-ID authentication, messaging, real events/RSVPs, moderation workflow, reporting, support-directory integrations, and production security are not implemented.
- Not connected to MTN systems and not an official MTN service. MTN name/branding is used here only to illustrate a concept; any real deployment requires appropriate authorization.

## Privacy and safety principles
A production version should use approved identity verification, data minimisation, explicit access controls, transparent retention policies, trained moderation, and country-specific privacy/employment reviews. It should not expose private conversations or individual wellbeing information to managers.

## Deploy with GitHub Pages
In the repository settings, open **Pages**, select **Deploy from a branch**, choose branch `main` and folder `/ (root)`, then save. Once GitHub Pages finishes deploying, the public site URL will appear in that settings page.

This prototype is for product exploration, not production use.
